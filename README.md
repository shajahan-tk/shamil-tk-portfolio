# SHAMIL TK Portfolio

Modern React portfolio for:
- IT Support
- Web Design
- Software Development
- AI Implementation

## Run locally

```bash
npm install
npm run dev
```

## Important customization

Open `src/App.jsx` and replace:
- `your@email.com`
- `+971 XX XXX XXXX`
- LinkedIn / GitHub links (`href="#"`)
- Project descriptions with your real projects
- Any skill or service text you want to change

## Build for production

```bash
npm run build
```

The production files will be generated in `dist/`.
